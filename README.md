# BREATHE_R
Hands-on course on time-series modelling for environmental epidemiology using R.

This repository contains all teaching materials used in the course Running Health Models in R. The course introduces the complete workflow for analysing short-term associations between environmental exposures and health outcomes using *Distributed Lag Non-Linear Models (DLNMs)* and *multivariate meta-analysis*.

The scripts were designed to be fully reproducible and are intended for students and researchers interested in environmental epidemiology, climate and health, and time-series analysis.
Course objectives
Participants will learn how to:
prepare environmental and health time-series data;
fit first-stage time-series models using DLNMs;
perform second-stage multivariate meta-analysis;
obtain Best Linear Unbiased Predictions (BLUPs);
estimate Minimum Mortality Temperature (MMT);
compute attributable health impacts;
visualize exposure-response associations.
